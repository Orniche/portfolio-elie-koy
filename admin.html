Connexion à la gestion

Votre clé d’accès GitHub autorise les modifications de ce portfolio. Elle reste en mémoire pendant cette session et n’est pas enregistrée dans le navigateur.

Première connexion : préparer ma clé

Sur le compte propriétaire du dépôt, ouvrez GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Créez une clé limitée au dépôt portfolio-elie-koy, avec uniquement la permission Contents : Read and write. Choisissez une date d’expiration. Copiez-la ici. Ne partagez pas cette clé et ne l’ajoutez jamais aux fichiers du site.

Le dépôt appartient actuellement à Orniche. Pour un accès personnel à Elie, transférer d’abord le dépôt sur son compte puis adapter le propriétaire dans admin.js.
